02 · DATASET PAGES

Dataset pages — kill the rainbow.

The 7 dataset pages (INSS, Bolsa Família, Pé-de-Meia, Bancos, Comex, Empresas, PIX) share a structure: header + filters + KPI strip + 2-3 chart panels + a table. They look different from each other because each one passes its own color array. With one rule — monochrome by default, accent for the highlighted slice — they collapse into one consistent visual.
