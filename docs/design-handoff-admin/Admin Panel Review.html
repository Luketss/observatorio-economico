Observatório Econômico Municipal · Admin design review · 17 mai 2026

Admin panel, aligned with the dashboard.

The admin panel is currently styled with Tailwind utilities (slate / violet) and lives outside the NID design system that powers the dashboard. This review brings the two surfaces into the same vocabulary — sidebar, topbar, tables, KPI strip, modals, empty states — and proposes admin-only patterns (bulk actions, status pills, dataset cards) that aren't needed on the user-facing side.

01 · SHELL

Admin shell — sidebar & topbar.

The admin sidebar today is a hard violet-on-slate panel. The dashboard sidebar is themed and quiet. Bring them into the same vocabulary: same nav-item style, same active-state pattern (left-border + tinted background), same topbar shape. Use a slightly cooler accent — purple (--accent-3) — so the user can tell at a glance they're in admin, but it still belongs to the same family.

Página renderizada com tokens NID (mesma família do dashboard) — alterna automaticamente entre neon, aurora, sunset, minimal e light.
  • Sidebar gradient + nav-active pattern mirror the dashboard's (.nid-nav-item.active + tinted-bg + left border).

02 · OVERVIEW

A KPI strip at the top of every admin page.

The admin currently jumps straight into a list. A compact 4-up strip at the top of each page summarizes the state of the thing you're managing — total count, distribution, last sync, queue depth. Different KPIs per page; same shape across the admin.

03 · MUNICÍPIOS

Municípios — table + bulk actions + plano switcher.

The current table cycles plano on click (free→pro→premium→free). Useful for a single row, painful for "promote these 12 cities". Move plano onto a pill + a per-row dropdown, add row checkboxes and a sticky bulk-actions toolbar, surface "última atualização" inline so the admin can see staleness without clicking in.

04 · INSIGHTS IA

Insights IA — dataset cards with status & queue depth.

The current page shows insights per município per dataset. Make each dataset a self-contained card with: status pill, last generation timestamp, bullets preview, and inline actions (gerar / aprovar / esconder). The page becomes a true control panel — at a glance, what's stale, what's pending review, what's live.

06 · EXPLORER

The Explorer is the "raw data" admin tool. Two improvements: table browser on the left (grouped by source) so picking a table is one click; filter chips above the results so active filters are visible and dismissable; column types color-encoded in the header.

07 · MODAIS + ESTADOS

Modals, forms & empty states.

The current admin uses raw Tailwind-styled divs for modals and a generic "Sem dados" string for empty. Bring both into the NID system: .nid-panel-shaped modal, theme-token inputs, and shape-aware empty states with explicit next steps.
